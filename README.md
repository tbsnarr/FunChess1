# Shuffle Chess

A browser based chess variant. Play standard chess; after every three individual turns (plies), the pieces on each side randomly trade squares. The side to move does not change during the shuffle.

## Play locally

Open `index.html` in a modern browser with an internet connection. The game uses chess.js from esm.sh for standard chess rules.

## Publish on GitHub Pages

1. Create a GitHub repository and add `index.html` at the repository root (or upload the contents of this folder).
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will provide the published site URL after deployment.
